    Definitions & the maths behind each label
    Distance
    ε-neighbourhood
    Nε(p) = { q ∈ D : d(p,q) ≤ ε }
    Because d(p,p) = 0, a point is always inside its own neighbourhood and counts toward MinPts.
    Core point
    |Nε(p)| ≥ MinPts: the point sits in a dense region.
    Border point
    Not core itself, but it lies inside Nε of at least one core point. It joins that cluster but cannot grow it.
    Noise point
    Neither core nor border. A point may be labelled noise early and be re-labelled border later.
    Directly density-reachable
    q is directly density-reachable from p if p is core and q ∈ Nε(p).
    Density-reachable
    There is a chain p = p1, p2, …, pm = q where each pi+1 is directly density-reachable from pi.
    Density-connected
    p and q are both density-reachable from some point o.
    Cluster
    A maximal set of density-connected points: if p is in the cluster and q is density-reachable from p, then q is in the cluster too.
    Why a queue?
    The queue (frontier) holds points found near a core point that still need their own region query. Every core point it reveals adds more points, so the cluster spreads along chains of density-reachability until the queue is empty.

    Each region query here checks every point, so a full run costs O(n²) distance computations. Neighbour test uses d ≤ ε with a 10⁻⁹ tolerance for floating-point rounding.
